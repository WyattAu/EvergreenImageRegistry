# Vm operator

Evergreen hardened VictoriaMetrics Operator - Kubernetes operator for VictoriaMetrics

| Attribute | Value |
|-----------|-------|
| Version | 0.45.0 |
| Tier | 1 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/vm-operator:0.45.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
