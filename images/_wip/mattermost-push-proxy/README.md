# Mattermost push proxy

Mattermost Push Proxy - push notification proxy for Mattermost mobile apps

| Attribute | Value |
|-----------|-------|
| Version | 1.1.0 |
| Tier | 2 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/mattermost-push-proxy:1.1.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
