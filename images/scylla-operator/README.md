# Scylla operator

Evergreen hardened ScyllaDB Operator - Kubernetes operator for ScyllaDB

| Attribute | Value |
|-----------|-------|
| Version | 1.13.0 |
| Tier | 1 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/scylla-operator:1.13.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
