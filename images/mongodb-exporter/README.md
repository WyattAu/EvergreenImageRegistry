# Mongodb exporter

Evergreen hardened MongoDB Exporter (dcu) - Prometheus exporter for MongoDB

| Attribute | Value |
|-----------|-------|
| Version | 0.13.0 |
| Tier | 1 |
| Base Image | scratch |
| Architecture | multi-arch |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/mongodb-exporter:0.13.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
