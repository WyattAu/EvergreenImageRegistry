# Mattermost operator

Mattermost Kubernetes Operator - manages Mattermost deployments on Kubernetes

| Attribute | Value |
|-----------|-------|
| Version | 1.12.0 |
| Tier | 2 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/mattermost-operator:1.12.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
