# Arangodb starter

ArangoDB in starter mode for cluster and resilient single-server deployments

| Attribute | Value |
|-----------|-------|
| Version | 3.11.10.1 |
| Tier | 1 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/arangodb-starter:3.11.10.1
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
