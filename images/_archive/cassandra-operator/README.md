# Cassandra operator

Evergreen hardened cass-operator - Kubernetes operator for Apache Cassandra

| Attribute | Value |
|-----------|-------|
| Version | 1.20.0 |
| Tier | 1 |
| Base Image | scratch |
| Architecture | amd64 |

## Usage

```bash

```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
