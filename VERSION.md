## Supply Chain Trust (P117-P118)

Every image built by CI now has:
- ✅ **Cosign signature** (keyless via Sigstore OIDC)
- ✅ **SPDX SBOM** (auto-generated by Syft from built image)
- ✅ **CycloneDX SBOM** (auto-generated by Syft)
- ✅ **SLSA v1 provenance** attestation
- All attached as cosign attestations — see `docs/verifying-images.md`

## CI Pipeline

- **Nightly:** Builds all 708 images, pushes to GHCR
- **Multi-arch:** amd64, arm64, s390x, ppc64le (QEMU + buildx)
- **Build:** Plain `docker build` or `docker buildx build --push`
- **Push:** GHCR only
- **Sign:** Cosign keyless signing (inline in build pipeline)
- **SBOM:** Syft SPDX + CycloneDX (inline in build pipeline)
- **Provenance:** SLSA v1 (inline in build pipeline)
- **Smoke test:** Post-build shim binary check
- **Security scan:** Trivy nightly
