# Drone autoscaler

Drone Autoscaler - automatic scaling for Drone runners

| Attribute | Value |
|-----------|-------|
| Version | 1.5.0 |
| Tier | 2 |
| Base Image | scratch |
| Architecture | amd64 |
| Health Check | exec |
| SBOM | [sbom.spdx.json](sbom.spdx.json) |

## Usage

```bash
docker pull ghcr.io/wyattau/evergreenimageregistry/drone-autoscaler:1.5.0
```

## Security

- Non-root by default
- HEALTHCHECK enabled
- SBOM available ([sbom.spdx.json](sbom.spdx.json))
- Digest-pinned base images
